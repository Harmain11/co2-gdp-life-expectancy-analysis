# CO2 GDP Life Expectancy Analysis

## Overview
This notebook analyzes public data on CO2 emissions per capita, GDP per capita, and life expectancy from Our World in Data. It demonstrates loading, standardizing, and visualizing these datasets to explore potential relationships.

## Features
- Import and clean datasets from external URLs
- Load CO2 emissions, GDP, and life expectancy data into pandas DataFrames
- Preliminary data inspection and standardization
- Visualization setup using matplotlib and seaborn

## Tech Stack
- Python
- Jupyter Notebook / Google Colab
- Libraries: numpy, pandas, scipy, matplotlib, seaborn

## How to Use
1. Open the notebook in Jupyter or Google Colab.
2. Run all cells sequentially to load and explore the datasets.
3. Modify or extend analysis as needed.
